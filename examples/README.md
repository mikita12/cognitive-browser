# Examples and Automation Scripts

This folder contains illustrative automation scripts demonstrating how Cognitive Browser interacts with real-world web pages and workflows.

## Available Examples

- `olx_deal_hunter.py`: Demonstrates semantic filtering and item exploration on marketplace listings.
- `wroclaw_pizza_hunter.py`: Demonstrates verifying online ordering capabilities across local business websites.
- `wikipedia_speedrunner.py`: Demonstrates semantic link navigation across encyclopedic content.
- `test_impossible_scenario.py`: Demonstrates escalation behavior when targeted actions cannot be fulfilled via Reflex Core alone.
- `decision_pool.py`: Standalone CLI demonstrating DeBERTa NLI scoring over accessibility element candidates.
